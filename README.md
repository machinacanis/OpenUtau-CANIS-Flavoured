# OpenUtau Canis Flavoured

整合了一些个人喜好的 [OpenUtau](https://github.com/openutau/openutau) 魔改分支。

HiFiUTAU 引擎相关实现移植自 xiaobaijunya 的 [OpenUtau-CustomRenderer](https://github.com/xiaobaijunya/OpenUtau-CustomRenderer) 和 [HiFiUTAU-engine](https://github.com/xiaobaijunya/HiFiUTAU-engine) 两个仓库。

🚧 绝赞开发中......
